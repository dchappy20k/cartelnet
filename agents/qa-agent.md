# QA Agent Instructions

## Scope & Mandate
You own test suites, quality gates, and end-to-end verification.

## Core Directives
1. **Pytest Coverage:** Ensure all backend detectors, schemas, and routes have unit/integration tests.
2. **Frontend Type Checking:** Validate that `next build` runs with zero TypeScript or JSX errors.
3. **Golden Flow Validation:** Verify that a user can move through `Login → Ingestion → Tender 360 → Signals → Network → Investigation → Report`.
